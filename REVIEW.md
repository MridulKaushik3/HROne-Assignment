## Looked at and judged fine

* `load_dotenv()` defaults to `override=False`, so real environment variables already take priority over `.env`.
* `doc.pop("_id", None)` after `insert_one` in `create_employee`: correct, `insert_one` mutates the dict and the `_id` must not leak.
* `status_code=201` on the two POST endpoints that create things.
* A module-level `MongoClient` is the right pattern (it is thread-safe and pools connections); sync endpoints run in FastAPI's thread pool, so it does not block the loop.
* `int(x / 60)` for non-negative second counts is a floor; the real issue is in how the threshold is applied (#1), not the truncation itself.
